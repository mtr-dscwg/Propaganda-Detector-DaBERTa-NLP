## Qualitative observations (seed 13)

- **Repetition** drops from 0.709 (gold spans) to 0.087 end-to-end: the earlier occurrence
  of a repeated phrase is often outside the model's context (256-token SI windows, 400
  characters around each TC span). On a short satirical article that fits in one window,
  Repetition was detected.
- **AP wire copy (in-corpus):** a neutral crime report produced 0 spans.
- **AP political article (2026):** 23 spans, almost all inside quotation marks, from both
  parties. The model detects propaganda techniques in quoted speech, not whether the
  article itself is propaganda. A few misfires in AP's own voice. Motivates separating
  narrator voice from quotes.
- **Babylon Bee satire:** techniques correctly detected, since satire imitates them, but
  the model cannot detect satirical intent.

## Caveats

- Dev is a 30-article holdout from train; small, so single-run swings are large.
- The best epoch is selected on dev, so dev scores are slightly optimistic.
- Leaderboard-comparable numbers require submitting `evaluate.py --split test` output.
- Training peaks around epoch 5–6; epochs 7–8 usually decline (overfitting on ~340 articles).
  The best checkpoint is kept.

## Appendix: experiments (day 2)

### C. CRF ablation (seed 13, single run)

| Stage 1 | SI F1 (dev) |
|---|---|
| With CRF (seed 13, original run) | 0.4941 |
| With CRF (6-seed mean) | 0.4840 ± 0.0124 |
| Without CRF (`si.use_crf=false`) | 0.4583 |

CRF contributes about +2.6 F1 against the seed mean (+3.6 against the same seed), consistent
with ApplicaAI's reported +2.2. Single seed for the no-CRF side; a 5-seed ablation is pending.

**Incident:** the no-CRF run saved into `runs/si-base-s13` and overwrote the original CRF
model, because run names didn't include the CRF setting. Fixed in `Config.run_name`
(`si-nocrf-...`); the ablation run was renamed to `si-nocrf-base-s13`, and the CRF seed-13
model was retrained (dev SI F1 0.4920 vs the original 0.4941). Recorded numbers for the
original run remain valid.

### E. NONE class (D4), seed 13, single run

| | SI F1 | TC micro (gold) | FLC F1 | FP rate |
|---|---|---|---|---|
| Baseline, original stage 1 | 0.4941 | 0.6714 | 0.2787 | 0.3333 |
| NONE, retrained stage 1 | 0.4920 | 0.6679 | 0.2458 | 0.3411 |
| Baseline, retrained stage 1 | *pending* | | | |

- Gold-span TC is unchanged, as expected (NONE is never predicted on gold spans).
- **NONE did not reduce the FP rate, and FLC dropped.** The likely explanation is that NONE
  also rejects some correct spans. To confirm, compare `n_pred` in both
  `dev_metrics.json` files.
- **Likely cause:** NONE examples were built from stage 1's false positives on its own
  training articles, which differ from its false positives on unseen text (train/test
  mismatch). Count of NONE examples from `build_none.py`: *to fill in*.
- **Proposed fix: cross-fitting.** Train stage 1 on half A of train and collect false
  positives on half B, and vice versa, so all NONE examples come from unseen articles.
- **Caveat:** single seed; seeds 1 and 13 differ by 0.023 in FLC, so the 0.033 gap is
  suggestive, not conclusive. The matched baseline (retrained stage 1 + `tc-base-s13`)
  is still to run.

| 0.33 | Thought-terminating Cliches | Rhetorical question about who will push rock carts |
| 0.30 | Causal Oversimplification | Prediction of total economic collapse |

Findings:
- **Satire imitates propaganda, so the techniques really are present** (fear appeals,
  exaggeration, rhetorical questions), and the model finds them. It cannot detect
  satirical intent.
- **Repetition is detected here** (short article, fits in one or two windows), unlike on dev
  (FLC 0.087). This supports the context-window explanation.
- **Low-confidence labels are the questionable ones:** "total economic collapse" at 0.30
  (Exaggeration would fit better) and an exclamation labelled Loaded Language.
